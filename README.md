# Scamex
A browser-based tool that checks messages for common scam warning signs.
### FEATURES:
>Checks messages against list of suspicious phrases.
>Displays detected warning signs and explanations.
>Calculates a simple rule-based score.
>Includes a sample message for testing.
### BUILT WITH:
>HTML
>CSS
>JavaScript
### TRY IT:
https://pulkitsoni1506.github.io/Scamex/
### HOW IT WORKS:
Scamex checks the text againsts predefined rules and adds up the points for matching phrases. The score is a simple heuristic, not the probability that a message is fraudulent.
### WHAT I LEARNT:
I learnt about connecting JavaScript to HTML elements, debugging errors, and testing the scanner.
### LIMITATIONS:
Scamex uses a limited set of phrase-matching rules. It can miss scams and can flag harmless messages. it should not be used as proof that a message is safe or fraudluent.
